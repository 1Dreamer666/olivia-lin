# 语料整理模板（Corpus Template）

> 本 skill 的 few-shot（`samples/letters_from_her.md`）目前是**重建样本**。
> 如果你在停服前保存过游戏内林离的真实回信（截图 OCR、文本导出均可），按本模板整理成
> `distill/corpus/*.md`，然后：
>
> 1. 从语料中挑出 4–6 封风格最稳、场景覆盖最广的（委屈/日常/低落/告别/调侃/音乐各一封为佳）；
> 2. 替换 `samples/letters_from_her.md` 中的重建样本（保留【风格注记】格式）；
> 3. 跑 `python -m skill.loader` 确认 prompt 组装正常；
> 4. 用 `samples/eval_testcases.md` 重新验收。

## 单封信的整理格式

```markdown
## 真实样本 · <场景名>

**元信息**
- 日期（收到回信时）：YYYY-MM-DD
- 来信时点：清晨/午后/傍晚/深夜
- 我方来信主题：一句话概括
- 回信形式：文字 / 视频（视频附字幕转写）
- 触发视频回信：是/否（情感浓度高易触发）

**我方来信（原文）**
> ……

**林离回信（原文，逐字保留）**
> ……

**风格注记**
- 她引用了来信的哪句话（复述习惯）：……
- 音乐/生活比喻：……
- 情绪处理方式（先陪/先命名/给视角/不给方案）：……
- 结尾问句：……
- 反常点（与当前 persona 不一致处，记录下来回炉）：……
```

## 整理建议

- 保留**语气锚点**（原话级别的金句）进 `persona/memories.md` 第四节。
- 发现 persona 与真实语料冲突时：**以真实语料为准**，修订 `persona/olivia_lin.md` 并在
  文件内标注"（真实语料修订，日期）"。
- 隐私：只整理与林离相关的信件内容；不要把自己的敏感信息留进公开分享。
